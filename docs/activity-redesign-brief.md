# Brief: Transaction Activity Redesign (FY26)

Surface: SoFi Money "Activity" — the L1 module on the account home + the full
transaction list. Members are confused by pending vs scheduled items and don't
trust when money actually moves. Goal: improve scannability + trust, support the
P2P volume push.

Open questions:
- Should scheduled payments sit above or below pending in the list?
- How do we represent a P2P payment that's reversible for 30 min?
